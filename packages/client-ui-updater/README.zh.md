# @deepseek-ai/dsh-client-ui-updater

中文 | [English](README.md)

自更新系统的浏览器端。注册 **自动更新** 设置页（一个 `settings.section` 条目，
`id: updater`），通过 api-remotes 装配与 Host 端的 `updater` 远程命名空间通信：

- **状态卡片**——本地/上游 sha、领先/落后、已修改/未跟踪本地草稿数量、上次检查
  与应用时间，以及阶段徽标；
- **计划卡片**——传入提交、变更文件数、`需要安装 / 需要重建 / 需要重启` 分类，
  以及草稿冲突清单（`conflictRisk`、`untrackedRisk`）；
- **需授权的操作**——应用更新（快进 + 暂存恢复草稿）、重启（受监督地重启 DSH）、
  恢复（回退到更新前的安全备份），三者都会先弹出确认对话框；未经点击确认，绝不
  执行任何破坏性操作；
- **配置编辑器**——自动检查 / 自动应用 / 需要授权等开关、轮询间隔、构建命令；
  补丁由 Host 端持久化；
- **实时刷新**——页面订阅转发事件 `updater/state`，并每 30 秒重新拉取一次
  `status()`，因此在应用更新过程中（安装/构建的滚动输出）以及任何冲突/错误状态
  都能即时呈现。

该页面只是一个“读取 + 授权”视图：所有状态与变更都发生在 Host 更新器服务中。

## 模型体验

无——这是浏览器设置界面，与模型无关。

#### KV 缓存影响

无；本包从不组装模型输入。

## 已知限制与后续工作

- **仅状态轮询**——实时进度依赖事件；30 秒轮询只是事件丢失时的兜底，不保证亚秒
  级新鲜度。
- **无内嵌冲突编辑器**——暂存弹出冲突时，页面会列出文件并指引 `git status`；
  完整的解决/合并界面留待后续。
- **重启默认需授权**——没有用户点击重启对话框，页面绝不会重启 Host。
