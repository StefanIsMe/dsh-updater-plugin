# Security Policy

## Reporting a Vulnerability

Open an Issue using the Bug report template and add the `security` label. Do not disclose exploits publicly.

We aim to triage within 48 hours.

## Scope

- Host updater pipeline (git capture, stash/backup, merge, restore, supervisor)
- Client updater (state handling, remote calls)
- Git Cordis plugin (pwsh shell handling, sandbox awareness)
