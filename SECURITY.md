# Security Policy

Your trust matters. If you discover a security vulnerability, please let us know responsibly.

## Reporting a Vulnerability

- Open an Issue using the **Bug report** template and add the `security` label
- Please don't disclose exploits publicly — we triage security reports within 48 hours
- Include steps to reproduce, impact, and any relevant logs (redact personal paths)

## Scope

We welcome reports covering:

- Host updater pipeline (git capture, stash/backup, merge, restore, supervisor)
- Client updater (state handling, remote calls)
- Git Cordis plugin (shell handling, sandbox awareness)

Thank you for helping keep the ecosystem safe!
